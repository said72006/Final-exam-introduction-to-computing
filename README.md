# ☕ Java Training Course Website

A responsive introductory website built with **HTML and CSS** as a web development / computing course project.

The website presents a Java training course, recommended learning resources, course levels, and a simple registration form.

## ✨ Features

- Java course landing page
- Navigation links to learning playlists
- Course overview section
- Course-level table
- Registration form preview (no actual enrollment or data submission)
- Custom styling with CSS
- Images and Java branding assets
- Responsive viewport configuration

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📚 Course Content Displayed

The website presents three learning stages:

| Course | Hours | Level |
|---|---:|---|
| Java Basics | 12 | Beginner |
| Java OOP | 15 | Intermediate |
| Java Projects | 18 | Advanced |

## ▶️ How to Open

No installation is required.

1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. Make sure the `Css` and `Img` folders remain in their original locations.

## Privacy note

The registration UI is **a demo**, not a live service: submitting it validates fields in the browser, shows a message, and resets the form. No data is saved or transmitted. Real enrollment requires a backend and a published privacy policy.
